<h1 class="font-bold text-7xl">Colophon.</h1>
<p class="text-xl mt-4">How this site is built.</p>

<p class="font-bold mt-4 text-lg">Building the site</p>
<ul>
    <li><strong><a href="https://www.11ty.dev">Eleventy</a></strong> turns the Markdown and Nunjucks templates into a static site.</li>
    <li><strong><a href="https://tailwindcss.com">Tailwind CSS</a></strong> styles the pages. <a href="https://postcss.org">PostCSS</a> processes it and strips out anything unused.</li>
    <li><strong><a href="https://webpack.js.org">webpack</a></strong> bundles the CSS and JavaScript.</li>
</ul>
<p class="font-bold mt-4 text-lg">Photos</p>
<ul>
    <li><strong><a href="https://www.11ty.dev/docs/plugins/image/">Eleventy Image</a></strong> resizes each photo and converts it to AVIF and WebP.</li>
    <li><strong><a href="https://photoswipe.com">PhotoSwipe</a></strong> provides the full-screen photo viewer.</li>
</ul>
<p class="font-bold mt-4 text-lg">Icons</p>
<ul>
    <li><strong><a href="https://heroicons.com">Heroicons</a></strong> for the navigation icons.</li>
    <li><strong><a href="https://simpleicons.org">Simple Icons</a></strong> for the LinkedIn and GitHub icons.</li>
</ul>
<p class="font-bold mt-4 text-lg">Hosting</p>
<ul>
    <li><strong><a href="https://github.com/pk2004/pk2004.github.io">GitHub</a></strong> hosts the source code.</li>
    <li><strong><a href="https://www.netlify.com">Netlify</a></strong> builds and hosts the site.</li>
</ul>
